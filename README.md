# SDG Community Assistant + LLM Systems

This repository contains three production-focused GenAI projects:

## 1. SDG Case-Based Community Assistant
Maps community problems to SDGs and retrieves similar global cases to generate actionable solutions.

## 2. LLMOps Platform for Local and Hybrid Inference
Implements model serving, routing, monitoring, and deployment pipelines for LLM/SLM applications.

## 3. Production SLM Fine-Tuning and Evaluation Framework
Provides LoRA/QLoRA fine-tuning workflows and benchmarking across latency, accuracy, and reliability.
